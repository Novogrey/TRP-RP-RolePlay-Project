Доступ

Введите личный идентификатор работника. Доступ к каждому разделу определяется отдельно.

Открытые заявления

Показываются только заявления, доступные вам для проверки.

Доступные даты

Даты берутся из того же графика, что и команда /график-смен. Создание доступно только сотрудникам с правом ДТУ.
